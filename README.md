# Exponent

An open, reproducible court for the scaling laws quant finance argues about: is volatility rough, and is the square-root law of market impact universal?

Exponent scores every estimator against synthetic markets where the true answer is known, maps where each one can identify that answer, and only then rules on fully public market data under pre-registered rules.

**Status:** proposal stage. No code yet.
